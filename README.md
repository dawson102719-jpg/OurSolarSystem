# Our Solar System Webiste

## Project Option
Website

## Project Description
The user will takea  guided tour of the solar system, learning about each of the planets and then taking a quiz on their knowledge.

## Theme Interpretation
The project is about the solar stystem.

## Intended User or Player
Students who are currently learning about the solar system.

## User or Player Goal
Learn about the different planets well enough to take a quiz on them.

## Main Features
Indiviudal pages featuring  informaiton on each planet and a quiz that gives you a score.

## JavaScript Features
The quiz at the end and each of the buttons utilizes javascript.

## Responsive Design
Images resize and text wraps.

## User Testing
The testers responded to every single task that was asked of them. According to their tests,
they were successfully able to click on each planet icon and were taken to the
corresponding page. They did not have an issue with following the layout or design of my
website and said that it was easy to follow. They also had good results when testing the
user feedback of the hover states of the buttons, and good feedback about resizing when
changing the size of the screen. One of the main issues that the testers had was with the
quiz and home buttons respectively. They said that they were too small compared to the
other buttons and icons present on the website and needed to be reworked to not be so
easily missed. The only other critique that I received was to ensure that I finish up polishing
the informative pages and adding the necessary quiz material to the final section of the
project.
